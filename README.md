## Overview

**Crowned & Cursed** brings a new set of powerful choices to Minecraft: claim the authority of a Crowned Decree, or wield the dangerous power of a Forbidden Curse. Explore **40 custom enchantments**—20 Decrees and 20 Curses—through a royal-themed experience built around a handcrafted **3D Royal Codex** and a distinctive gilded-obsidian interface.

This repository is the public home for project documentation, license information, and the community bug tracker. The mod's Java source code is private and is not included here.

## Features

- **40 custom enchantments**
  - **20 Crowned Decrees** for abilities fit for royalty.
  - **20 Forbidden Curses** for powers that come with a cost.
- **3D Royal Codex GUI** for a themed in-game experience.
- **Custom advancements** to complement the mod's content.
- **Structure loot injection** to bring mod content into the world.
- **Configurable gilded-obsidian UI** to tailor the look of the interface.

## Compatibility

- **Minecraft:** Java Edition 1.20.1
- **Mod loader:** Fabric
- **Required dependency:** Fabric API
- Check the release or download page for any additional version-specific requirements.

## Installation

1. Install Minecraft Java Edition **1.20.1**.
2. Install the **Fabric Loader** for Minecraft 1.20.1.
3. Install **Fabric API**.
4. Download the compatible Crowned & Cursed release and place its `.jar` file in your Minecraft `mods` folder.
5. Launch the game using your Fabric profile.

## Bug reports and suggestions

Found a bug or have an idea for a new enchantment? Please use the repository's [Issues page](https://github.com/SeaSerpant1040/Crowned-and-Cursed/issues). When reporting a bug, include your Minecraft version, Fabric Loader version, other installed mods, and clear reproduction steps.

For enchantment ideas, use the Issue templates and tell us whether it is a Crowned Decree or Forbidden Curse, along with its intended effect and balance notes.
